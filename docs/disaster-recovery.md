# সংবাদচক্র — ডেটা ব্যাকআপ ও দুর্যোগ পুনরুদ্ধার পরিকল্পনা (Disaster Recovery & Backup Guide)

এই নির্দেশিকায় সংবাদচক্র (SongbadChakra) পোর্টালের ডেটাবেজ ব্যাকআপ, ডেটা রপ্তানি এবং সার্ভার বিপর্যয়ের সময় জরুরি পুনরুদ্ধার প্রক্রিয়া নথিভুক্ত করা হলো।

---

## ১. Supabase ক্লাউড ব্যাকআপ ব্যবস্থা

সংবাদচক্রের প্রধান প্রোডাকশন ডেটাবেজ হোস্ট করা থাকে **Supabase (PostgreSQL 15+)**-এ।

### ১.১ স্বয়ংক্রিয় ব্যাকআপ
- **দৈনিক ব্যাকআপ:** Supabase প্রোজেক্টে স্বয়ংক্রিয়ভাবে প্রতি ২৪ ঘণ্টায় পুরো ডেটাবেজের ব্যাকআপ নেওয়া হয়।
- **সংরক্ষণ মেয়াদ:** ফ্রি ও প্রো টায়ার অনুযায়ী ৭ দিন থেকে ৩০ দিন পর্যন্ত ব্যাকআপ হিস্ট্রি উপলব্ধ থাকে।
- **অবস্থান:** Supabase Dashboard -> **Settings** -> **Database** -> **Backups**।

### ১.২ ম্যানুয়াল ব্যাকআপ গ্রহণ (CLI / pg_dump)
প্রোডাকশনে যেকোনো বড় মাইগ্রেশন বা আপডেটের পূর্বে ম্যানুয়াল ব্যাকআপ নিতে নিচের কমান্ড ব্যবহার করুন:

```bash
# PostgreSQL pg_dump কমান্ড
pg_dump -h db.<PROJECT_REF>.supabase.co -U postgres -d postgres -F p -f backup_$(date +%Y%m%d_%H%M%S).sql
```

## ২. লোকাল ডেটা রপ্তানি ও স্ন্যাপশট ব্যাকআপ

লোকাল ডেভেলপমেন্টে বা অফলাইন ব্যাকআপ হিসেবে `.data/portal-data.json` ফাইলে সম্পূর্ণ পোর্টালের ডেটা সংরক্ষিত থাকে।

### ব্যাকআপ তৈরি:
```powershell
# উইন্ডোজ পাওয়ারশেলে দ্রুত ব্যাকআপ তৈরি:
Copy-Item .data\portal-data.json .data\portal-data_backup_$(Get-Date -Format 'yyyyMMdd_HHmmss').json
```

### রিস্টোর পদ্ধতি:
```powershell
# পূর্বের ব্যাকআপ ফাইল পুনরুদ্ধার:
Copy-Item .data\portal-data_backup_XXXXXXXX_XXXXXX.json .data\portal-data.json
```

## ৩. ডেটাবেজ স্কিমা ও সীড পুনরায় কার্যকর করা

সম্পূর্ণ নতুন একটি Supabase প্রোজেক্টে ডেটাবেজ পুনর্গঠন করতে:

1. **SQL Editor** ওপেন করুন।
2. নিচের ফাইলগুলোর কোড ক্রমানুসারে চালান:
   - `supabase/migrations/20260905_create_articles.sql` (সংবাদ স্কিমা)
   - `supabase/migrations/20260905_create_contact_messages.sql` (বার্তা স্কিমা)
   - `supabase/migrations/20260906_create_sources_and_ai_logs.sql` (আরএসএস ও এআই লগ স্কিমা)
   - `supabase/migrations/20260906_seed_articles.sql` (প্রাথমিক সংবাদ ডেটা)
   - `supabase/migrations/20260906_ai_automation.sql` (AI অটোমেশন ইঞ্জিন)
   - `supabase/migrations/20260906_job_recovery.sql` (জব লিজ, রিট্রাই ও ডেড-লেটার কলাম)

অথবা নোড স্ক্রিপ্ট ব্যবহার করে সরাসরি সীড চালান:
```bash
node scripts/seed-supabase.mjs
```

## ৪. দুর্যোগ পরবর্তী পুনরুদ্ধার পরীক্ষা (Recovery Drill)

বছরে অন্তত একবার অথবা প্রধান ভার্সন আপগ্রেডের পূর্বে নিচের ধাপগুলো পরীক্ষা করুন:
1. ব্যাকআপ ফাইল থেকে টেস্ট ডেটাবেজে স্কিমা ও ডেটা রিস্টোর করা।
2. অ্যাডমিন প্যানেলে লগইন করে সংবাদ তালিকা ও ড্রাফট যাচাই করা।
3. ব্রেকিং নিউজ এবং সার্চ কার্যকারিতা পরীক্ষা করা।
4. RSS ফিড ইনজেশন সফলভাবে কার্যকর হয় কিনা তা পরীক্ষা করা।
